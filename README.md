# 🎮 Arcade Arena

## 📌 Project Summary

Arcade Arena is a Python-based arcade gaming platform that brings multiple mini-games together into one interactive application. It provides users with a centralized gaming experience where they can play different games, manage their profiles, track their performance, and compete through leaderboards.

The project combines game development with user authentication, database management, analytics, and an interactive graphical user interface.

## ✨ Features

- 🎮 Multiple arcade mini-games
- 🔐 User authentication
- 👤 Player profiles
- 🏆 Leaderboards
- 📊 Player statistics and analytics
- 💾 Database integration
- 🔊 Sound effects and game assets
- 🖥️ Interactive graphical user interface

## 🎯 Games Included

- 🎲 Dice
- 🧠 Memory
- ❓ Quiz
- 🐍 Snake
- ❌⭕ Tic-Tac-Toe

## 🛠️ Technologies Used

- Python
- SQLite
- GUI Development
- Object-Oriented Programming
- Modular Programming

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Samridhi-goyal/Arcade-Arena.git
```

### 2. Navigate to the project directory

```bash
cd Arcade-Arena
```

### 3. Run the application

```bash
python main.py
```

## 🎓 Project Objective

The main objective of Arcade Arena is to apply Python programming concepts to the development of a complete interactive application. The project demonstrates concepts such as modular programming, game logic, GUI development, authentication, database integration, and player performance tracking.
